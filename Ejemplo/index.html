02 · Código

El firmware, línea a línea


#include <Arduino.h>

const int LED   = 2;    // GPIO2 del ESP32
const int CANAL = 0;    // canal PWM

void setup() {
  ledcSetup(CANAL, 5000, 8);   // 5 kHz, 8 bits
  ledcAttachPin(LED, CANAL);
}

void loop() {
  for (int d = 0; d <= 255; d++) {
    ledcWrite(CANAL, d);       // sube el brillo
    delay(4);
  }
}

Reveal resalta un bloque de código en cada pulsación. El LED de la derecha hace lo que dice el loop().

Inmaker · Reveal.js
El plugin de resaltado colorea el código y lo recorre por bloques. Clic 1: las constantes, qué pin y qué canal PWM. Clic 2: la configuración. Clic 3: el bucle que sube el brillo. El código es texto real: se puede seleccionar y copiar.

Inmaker · Reveal.js
Una diapositiva de Reveal es HTML: puede llevar controles, cálculos o datos en directo. La fórmula la dibuja el plugin de matemáticas (KaTeX). Mueve Vin, R1 y R2 y la tensión de salida se recalcula al momento. Clic final: el mensaje de cierre.
